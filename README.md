# GCC Banking System

## Project Description
The GCC Banking System is a C++ console-based application developed to simulate basic banking operations.

## Features
- Display bank users.
- Deposit money.
- Withdraw money.
- Send cash to another user.
- Check account balance.
- User authentication using account numbers and PINs.

## Technologies Used
- C++
- Code::Blocks IDE

## Users
The system currently includes three sample bank users:
- Thando
- Lebo
- Sipho
